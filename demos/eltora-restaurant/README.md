# ELTORA RESTAURANT — website

Static site: HTML5, CSS3, vanilla JS, Three.js. No build step, no backend. Open `index.html` or run `python3 -m http.server 8000` in this folder.

## External resources (need internet)
- Three.js r128: `https://cdnjs.cloudflare.com/ajax/libs/three.js/r128/three.min.js`
- Google Fonts: Cormorant Garamond, Jost

## Photos
All 20 photos are bundled in `assets/images/` at original 1536x1024 resolution. The `IMG` list at the top of `script.js` maps names to files; swap any file to change a photo.
Edits made to the supplied photos: the exterior sign now reads ELTORA, and small "THE RESERVE" napkin text was retouched out of `table`, `scallops` and `fish`.
Demo content: chef profile, testimonials, address, phone, hours and menu prices are sample data.
