# ELTORA FITNESS

**Train Strong. Live Stronger.**

A cinematic, 3D-driven marketing site for a premium performance gym. Plain
HTML, CSS and vanilla JavaScript. No framework, no build step, no backend, no
database, nothing to install.

## Images (batch 1 of 2)

This version uses **20 supplied ELTORA images**, stored locally in `assets/images/`
(no stock libraries, no remote URLs, nothing generated by the build). See
`assets/images/README.md` for which image sits in which slot.

- The page has **38 image slots**, so some photos are used in more than one place,
  each time with a different crop set inline on the `<img>`. Once batch 2 arrives,
  swap the `src` (and `object-position` if needed) on the slots you want to replace.
- The **hero** has no backdrop photo; the 3D dumbbell is its image, as in the
  original design. There is a comment in `index.html` marking where to add one.
- The four coach images are poster-style graphics with each coach's name and
  tagline baked in, so the coach frames are 5:6 to show them uncropped.
- The people in these images are not real staff. They are kept labelled
  "Demo profile"; replace them (and remove the badges) when you have real coaches.
- Check everything at any time with `python3 tools/check_images.py` (needs Pillow).

## Run it

- **Double-click `index.html`.** It works from `file://`: all libraries and fonts
  are bundled and loaded as classic scripts.
- Or serve the folder: `python3 -m http.server 8000`, then open
  http://localhost:8000.

## Deploy

It is a static site. Upload the folder as it is.

- **Netlify:** drag the folder onto app.netlify.com/drop.
- **GitHub Pages:** push to a repo, then Settings, Pages, deploy from the root
  of the main branch.
- Any static host or CDN works.

## What is in the page

Hero (WebGL dumbbell, cinematic intro, scroll cue), Programs (6 cards),
Performance stats (animated counters), Cinematic banner (parallax and slow
zoom), Featured workouts (editorial grid), 3D equipment viewer (kettlebell,
plate, dumbbell), Coaches (4 demo profiles), Membership (3 tiers),
Progress, Studio (6 zones), Lookbook (10 frames with lightbox), Membership CTA,
Testimonials (3, marked demo), Free-session form (validated, front-end only),
Location and hours, Footer.

## The 3D

- **Hero:** a hex dumbbell with a knurled handle and a lime ELTORA end plate.
  It uses PBR metal, an environment map for reflections, a shadow-casting key
  light, a lime rim light, floating drift, mouse tilt, a camera dolly on entry,
  scroll-linked motion and drifting particles.
- **Equipment viewer:** drag to rotate, `+` and `-` to zoom, `Ctrl` or `Cmd` +
  scroll to zoom (plain scroll still scrolls the page), pinch on touch. Floating
  labels: Precision, Power, Performance.
- Both scenes pause when off-screen or when the tab is hidden.
- If WebGL is unavailable the hero falls back to a typographic version with a
  lime glow, and the viewer shows a short message.
- All models are built in code (`script.js`), so there are no separate 3D
  files to ship. See `assets/3d/README.md`.

## Make it yours

- **Colours and type:** the CSS custom properties at the top of `style.css`.
- **Copy, prices, hours, coaches:** plain text in `index.html`.
- **Demo content** is labelled on the page (statistics, pricing, coach
  profiles, testimonials, location and hours, the form). Replace it with real
  details and remove the `demo-note` lines and the `Demo profile` badges when
  you do. Do not present the stock-photo coaches or sample testimonials as real
  people.
- **Links to fill in:** the phone number in `CALL ELTORA` (`tel:+910000000000`),
  the Google Maps link in `GET DIRECTIONS`, and the Instagram, YouTube,
  Facebook, Privacy and Terms links in the footer (currently `#`).
- **The form** validates in the browser and shows a confirmation, but sends
  nothing. To receive leads, point it at a form service (Formspree, Netlify
  Forms, and so on) or your own endpoint.

## Accessibility and motion

Keyboard focus is visible, there is a skip link, the mobile menu closes on
Escape, the lightbox works from the keyboard, and `prefers-reduced-motion`
turns off smooth scrolling, reveals and most animation.

## Testing notes

Checked in headless Chromium at 1920, 1440, 1180, 1024, 820, 768, 390 and 360px
wide: all 37 image tags load with no broken images or placeholder panels, no
remote URLs, no horizontal overflow, no console errors, every reveal animation
fires, all nav links land on their sections, form validation and confirmation,
lightbox (mouse and keyboard), mobile menu, and the no-WebGL fallback. The 3D
scenes were rendered with a software GL renderer, so frame rate on real
hardware is untested. Safari, Firefox and real phones have not been tested.
