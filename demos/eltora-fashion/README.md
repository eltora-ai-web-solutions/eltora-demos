# ELTORA (fashion store demo)
Extract the ZIP and open `index.html` in a browser. Plain HTML, CSS and JS, with raw WebGL for the 3D fabric. Nothing is downloaded from the internet.

All 20 photos are in `assets/images/`, each used once (8 products, 5 categories, the Signature banner, 2 lookbook shots, 3 editorial stories, About).
The path for each slot is listed in the `M` object near the top of `js/app.js`. To swap a photo, replace the file and update its path there.
Product names, prices, sizes and colors are in the `P` array in the same file.
